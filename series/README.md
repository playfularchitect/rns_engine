# G4 Series Archive

This directory organizes the public, frozen output of successive G4 `rns_engine` research Series.

- [`G4s1/`](G4s1/) — Series 1, frozen and preserved.
- [`G4s2/`](G4s2/) — Series 2, not yet released.

G4 itself is private. These folders contain public `rns_engine` artifacts, evidence, replay information, manifests, and release metadata.

Each Series is a frozen public record of what was demonstrated at that stage. A later Series may add new results, broader scope, or stronger performance, but it will never rewrite the evidence or claim boundary of an earlier frozen Series.
